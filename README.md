# multipdf-rag
# 📄 MultiPDF RAG — Chat with Your PDFs

A Streamlit app that lets you upload one or more PDF files and ask questions about their content. It uses **Retrieval-Augmented Generation (RAG)**: your PDFs are split into chunks, embedded into a FAISS vector index, and the most relevant chunks are passed to **Google Gemini** to produce a grounded answer.

If the answer isn't in your documents, the model is instructed to say so instead of guessing.

---

## ✨ Features

- Upload **multiple PDFs** at once
- **Semantic search** over document content (not just keyword matching)
- Answers generated by **Gemini** using only the retrieved context
- **Local FAISS index** saved to disk for fast retrieval
- Simple **Streamlit** chat-style interface

---

## 🧠 How It Works

```
PDFs ──► Text extraction (PyPDF2)
      ──► Chunking (RecursiveCharacterTextSplitter, 10,000 chars / 1,000 overlap)
      ──► Embeddings (Google embedding-001)
      ──► FAISS vector store (saved to ./faiss_index)

Question ──► Embed question ──► Similarity search in FAISS
         ──► Top chunks + question ──► Gemini (gemini-1.5-flash, temp 0.3)
         ──► Answer shown in Streamlit
```

1. **Ingestion** – On clicking *Submit*, text is extracted from every page of every uploaded PDF and concatenated.
2. **Chunking** – The text is split into large overlapping chunks to preserve context across boundaries.
3. **Indexing** – Each chunk is embedded with `models/embedding-001` and stored in a FAISS index saved locally as `faiss_index/`.
4. **Retrieval** – When you ask a question, it is embedded and the most similar chunks are retrieved.
5. **Generation** – A LangChain "stuff" QA chain sends the retrieved chunks and your question to Gemini with a prompt that forbids answering outside the provided context.

## 🚀 Getting Started

### Prerequisites

- Python 3.9+
- A Google AI API key — get one from [Google AI Studio](https://aistudio.google.com/app/apikey)

### Installation

```bash
git clone https://github.com/kundanalekkala/multipdf-rag.git
cd multipdf-rag

python -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate

pip install -r requirements.txt
```

### Configuration

Create a `.env` file in the project root:

```env
GOOGLE_API_KEY=your_google_api_key_here
```

### Run

```bash
streamlit run app.py
```

Open the URL shown in the terminal (usually `http://localhost:8501`).

---

## 💡 Usage

1. In the sidebar, upload one or more PDF files.
2. Click **Submit** and wait for the "Done" message (this builds the index).
3. Type a question in the main text box.
4. Read the answer generated from your documents.
